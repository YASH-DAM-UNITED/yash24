# Yashwanth.L Portfolio

React/Vite portfolio prepared for GitHub and Cloudflare Pages.

## Run locally
npm install
npm run dev

## Build
npm run build

Cloudflare Pages build command: `npm run build`
Output directory: `dist`

## Character animation
The included storyboard is used as an interactive visual prototype. Cursor movement changes the character framing and entering the center triggers the greeting state. For true seamless head/eye tracking and headphone-removal animation, replace the storyboard asset with dedicated transparent animation clips or a rigged Rive/Spine/3D character while retaining the existing interaction state logic.
